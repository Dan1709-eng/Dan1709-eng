# Frontend Development Growth Roadmap

A practical plan for developing strong frontend skills through focused practice and finished projects.

## Weekly routine

Aim for five focused sessions per week, 60–90 minutes each:
- Learn one concept and take short notes.
- Practise by writing code yourself, not only watching tutorials.
- Build a feature that uses the concept.
- Commit meaningful progress to GitHub.
- Review what worked, what broke, and what to learn next.

## Phase 1 — HTML and CSS (Weeks 1–2)

- Semantic HTML, forms, labels, and accessible structure
- CSS box model, selectors, specificity, Flexbox, and Grid
- Mobile-first design, media queries, and responsive layouts
- Typography, spacing, reusable styles, and CSS variables

**Project:** Build a polished restaurant landing page that works on mobile, tablet, and desktop.

## Phase 2 — JavaScript (Weeks 3–5)

- Variables, data types, conditions, loops, and functions
- Scope, arrays, objects, and array methods
- DOM manipulation and event handling
- Forms and validation
- JSON, modules, promises, async/await, and error handling
- Browser developer tools and debugging

**Projects:** An interactive task tracker, then a searchable app that uses a public API.

## Phase 3 — Git and GitHub (Week 6, then ongoing)

- Practise status, add, commit, log, pull, and push
- Write meaningful commit messages
- Use branches for larger changes
- Write a README with purpose, features, setup, screenshots, and demo
- Never commit passwords, API keys, or other secrets

## Phase 4 — React (Weeks 7–9)

- JSX, components, props, and rendering lists
- State, events, conditional rendering, and forms
- Effects and fetching data
- Component composition and lifting state
- Routing and basic testing

**Project:** A responsive product catalogue or dashboard with search, filtering, and detail views.

## Phase 5 — Portfolio projects (Weeks 10–12)

Finish and polish three projects:
1. **Responsive landing page:** layout, accessibility, and mobile design
2. **JavaScript application:** interactions, validation, and persistence where useful
3. **React application:** reusable components, API integration, loading/error states, and routing

For every project:
- Test on mobile and desktop.
- Fix broken links and console errors.
- Add a clear README and screenshots.
- Publish a live demo where practical.
- Explain what you built and what you learned.

## After 12 weeks

Continue strengthening JavaScript, accessibility, performance, web security, testing, and debugging. Practise explaining your projects and gradually explore open-source contributions.

## Weekly checklist

- [ ] Five focused practice sessions completed
- [ ] Built or improved a real feature
- [ ] Committed meaningful work
- [ ] Updated documentation where needed
- [ ] Identified the next learning goal

**Measure progress by what you can build, explain, debug, and finish—not just tutorials watched or commits made.**

The timeline is a guide, not a deadline. Repeat a phase when you need more practice.
